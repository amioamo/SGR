# Nested Reference Panel Size

The beacon is drawn once per window, replicate, and beacon size. The reference
is a nested prefix of the complement, so every larger panel contains the smaller
panels. The method is template-count synthesis. Deltas are F1(R) minus F1(R=100)
on the same beacon.

## Configuration

- ancestry: EUR
- beacon sizes: 25, 50, 100
- panel sizes: 10, 25, 50, 100, 200, 400
- windows: 6
- replicates: 3
